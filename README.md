# QueueCare

Queue management desktop app in Java Swing, with a live client portal. Built for small offices and service desks — take a number, call it, track it.

## What's in here

- `QueueCare.jar` — the desktop app (`java -jar QueueCare.jar`)
- `raw.txt` — full app source (Swing UI plus an embedded HTTP server)
- `web/` — client portal, open `portal.html`
- `Video.mp4` — demo clip
